# HCIM Safety Check

The plugin replaces your Hardcore Ironman chat icon with a green helmet while you are in a supported safe-death area. An optional infobox provides an easier to spot identifier.

## Verified Areas and Conditions

All supported regions have been verified to work. A list of these areas can be seen below, or at the [OSRS Wiki page](https://oldschool.runescape.wiki/w/Ironman_Mode#Hardcore_Ironman) for the HCIM mode.

- Player-owned houses
- Camelot Training Room
- Magic Training Arena — Graveyard
- Galvek replay
- Glough replay
- PvM Arena
- Zulrah — after elite western diary completion, and with the daily revive available.
- Dream World during Lunar Diplomacy
- Koschei the Deathless during The Fremennik Trial
